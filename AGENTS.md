# Editing project.yaml

- Read [the project.yaml guide](docs/project-yaml.md) before writing or editing a `project.yaml`.
- Start new projects from [the project template](docs/project.template.yaml).
- Before pushing, run `scripts/check-project-yaml` and fix every reported problem.
- When a change alters what `project.yaml` supports, update `docs/project.schema.yaml` and the guide in the same PR.
